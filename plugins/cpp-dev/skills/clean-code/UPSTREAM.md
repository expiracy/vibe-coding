# Sources and adaptation

These 48 Clean Code topics derive from `skills/.experimental/clean-code` in
[pproenca/dot-skills](https://github.com/pproenca/dot-skills), version 1.0.7,
commit `cf93c57cac89d6fc3e4194686000411567f5caf3`.
They were adapted through the user's [expiracy/clean-code](https://github.com/expiracy/clean-code)
collection at commit `e9a84cc953a73588f2d180b86ac7a2940af62a93` and the former
`cpp-style` skill in this repository.

This split retains all 48 topic filenames, the ten categories, source citations,
and the original MIT licence. The rules are now language-neutral summaries:
language-specific examples and implementation advice were removed from this
skill. The main file provides a short overview and routes to individual rules.

Robert C. Martin's *Clean Code* (2008) supplies the named principles. This is an
independent adaptation, not the book's full text or an endorsement by its author
or the upstream project. Inherited impact labels are editorial categories,
not measurements of effectiveness or priorities that override correctness.
