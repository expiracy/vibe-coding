# Adding a Clean Code Rule

Keep the rule about a language-independent design or readability decision.
Copy a nearby rule's frontmatter, describe the principle and its practical
limits, and retain its source attribution. Use qualitative impact descriptions
unless a measurement supports a numerical claim.

When an example clarifies the rule, use short language-neutral pseudocode and
identify the specific improvement. For example, contrast an unexplained `fee`
with `shippingFeeCents` when the unit is part of its meaning.

Keep language features and library mechanisms in the relevant language skill.
Do not copy passages from the book or turn a useful principle into an absolute
quota for lines, arguments, classes, or assertions.
