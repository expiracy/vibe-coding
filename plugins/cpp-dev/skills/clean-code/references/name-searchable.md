## Use Searchable Names

Name significant domain values and policies so readers can find their definition and uses. Replace unexplained policy literals with names that communicate their role.

Use names proportional to scope: a short local loop name may be clear, while a shared policy needs a distinctive name. Do not name every obvious literal merely to satisfy this rule.

Reference: [Clean Code, Chapter 2: Meaningful Names](https://www.oreilly.com/library/view/clean-code-a/9780136083238/)
