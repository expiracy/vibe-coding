## Group Related Code Vertically

Keep related definitions close and separate distinct concepts with whitespace. Arrange code so readers can follow a high-level operation into its details without searching across unrelated sections.

Use existing file organization and formatter conventions. Avoid moving large areas of otherwise unrelated code just to impose a preferred reading order.

Reference: [Clean Code, Chapter 5: Formatting](https://www.oreilly.com/library/view/clean-code-a/9780136083238/)
