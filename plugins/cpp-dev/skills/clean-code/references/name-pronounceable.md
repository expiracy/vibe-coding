## Use Pronounceable Names

Use names that people can discuss in reviews and conversation. Prefer recognizable domain words to compressed consonants and unexplained abbreviations.

Keep established abbreviations that the intended readers understand. Expanding a familiar term into an unusual phrase can make the code harder to read.

Reference: [Clean Code, Chapter 2: Meaningful Names](https://www.oreilly.com/library/view/clean-code-a/9780136083238/)
