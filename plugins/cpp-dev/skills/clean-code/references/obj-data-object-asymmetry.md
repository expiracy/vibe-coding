## Choose Data or Behavior for the Expected Change

Data-oriented designs make it straightforward to add operations over a known set of data. Behavior-oriented designs can make it straightforward to add new implementations behind an established contract.

Choose for the changes the application actually needs. Neither approach is universally superior, and neither requires reorganizing correct existing code solely to match a pattern.

Reference: [Clean Code, Chapter 6: Objects and Data Structures](https://www.oreilly.com/library/view/clean-code-a/9780136083238/).
