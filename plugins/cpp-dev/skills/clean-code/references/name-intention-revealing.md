## Use Names That Reveal Intent

Name the domain concept, purpose, or result so callers can understand it without decoding the implementation. Include units or important distinctions when they affect correct use. Match established project vocabulary.

For example, `shippingFeeCents` communicates more than `f`. A longer name is useful when it removes ambiguity; length alone is not a quality measure.

Reference: [Clean Code, Chapter 2: Meaningful Names](https://www.oreilly.com/library/view/clean-code-a/9780136083238/)
