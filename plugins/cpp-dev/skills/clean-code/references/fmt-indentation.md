## Make Structure Visible Through Indentation

Indent nested work consistently so its control structure is easy to see. Avoid compressed formatting that conceals conditions, alternatives, or the extent of a block.

Use the existing formatter where available. Indentation should reveal the structure that is actually present, not disguise complex logic or substitute for clarifying it.

Reference: [Clean Code, Chapter 5: Formatting](https://www.oreilly.com/library/view/clean-code-a/9780136083238/)
