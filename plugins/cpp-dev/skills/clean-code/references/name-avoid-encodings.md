## Avoid Encodings in Names

Prefer names that describe domain meaning over prefixes that encode representation or implementation structure. `description` explains more than a type-prefixed abbreviation.

Respect the project's existing conventions during focused changes. Name implementations by their actual distinction rather than adding interface prefixes or implementation suffixes by habit.

Reference: [Clean Code, Chapter 2: Meaningful Names](https://www.oreilly.com/library/view/clean-code-a/9780136083238/)
