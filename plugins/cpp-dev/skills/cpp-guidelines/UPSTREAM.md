# Sources and scope

This skill separates the language-specific material from the former `cpp-style`
skill in [expiracy/vibe-coding](https://github.com/expiracy/vibe-coding).
It retains the independently written pointer/lifetime reference and C++ rule
template, and collects the C++ contracts previously mixed into design topics.
The original MIT licence remains in LICENSE.

The recommendations paraphrase the official
[C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines),
consulted on 19 October 2026. Rule IDs identify relevant sources. Examples target
C++20; a project's declared standard and contracts still govern.

The resource example originated in the user's C++ adaptation of
[expiracy/clean-code](https://github.com/expiracy/clean-code) at commit
`e9a84cc953a73588f2d180b86ac7a2940af62a93`. Its implementation contracts now live
here rather than in the language-independent design skill.

This is a focused independent guide, not an official endorsement, a complete
copy of the Core Guidelines, or a guarantee of language conformance.
