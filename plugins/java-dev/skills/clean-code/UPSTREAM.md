# Direct upstream source

This Java version is adapted directly from
[pproenca/dot-skills](https://github.com/pproenca/dot-skills), not from a downstream adaptation.

- Upstream path: `skills/.experimental/clean-code`
- Upstream commit: `cf93c57cac89d6fc3e4194686000411567f5caf3`
- Upstream skill version: `1.0.7`
- Local example baseline: Java 11

The source files were retrieved from this exact revision and verified against
their original Git blob hashes. All 48 rule filenames, ten categories, source
citations and the original MIT licence are retained. Each rule links to its
immutable upstream source. The long upstream rule index is kept in a reference
so the main skill file stays concise.

Adaptations preserve the principles and caveats while changing example language
and compatibility details. Unsupported numerical impact claims are made
qualitative, illustrative assumptions are identified, and context corrections
avoid treating line counts, abstraction patterns or error mechanisms as universal
requirements. The original upstream text remains available at each source link.

The original Java examples and explanations are retained where applicable.
Non-Java examples are removed. Record declarations are represented as Java 11
classes; the flag-condition and date examples receive narrow syntax/type
corrections, and the immutable-settings alternative uses a standard map copy.
Application, framework and JUnit excerpts still need their stated
context. The DTO classes illustrate data transfer, not every generated behavior
of a Java record.

The principles are attributed upstream to Robert C. Martin's *Clean Code*.
This is an independent language adaptation, not an endorsement by the book's
author or upstream maintainers. Compilation checks do not measure effectiveness
across models or establish production correctness.
